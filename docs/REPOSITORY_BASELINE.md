# SITARI DISKUM v3 source baseline

This repository establishes the current local application source before optimization or migration. No application behavior was changed for synchronization.

Active source: Admin/, Public/, Tamu-Luar/ and Tamu-FO/. Public is generated by maintenance/build-public.js from the authoring sources; its pinned Apps Script library version stays unchanged. Local preview and tests are in local-test/. Current deployment routing is in deployments/2026-11-01/projects.json. Apps Script project IDs and .clasp.json files are deployment configuration, not credentials. OAuth credentials must stay outside this repository.

## Private configuration and staff data

The following existing files remain local and are excluded from Git:

- Admin/DeploymentConfig.js
- Admin/EmployeeDirectory.js
- Admin/VisitPicContacts.js
- Admin/PublicIntake.js
- Tamu-Luar/Destinations.js
- Tamu-FO/Destinations.js
- local-test/previews/employee-directory.json

These files contain real staff identifiers, contact numbers, personal defaults, or generated copies of that information. Matching placeholders are stored under config-templates/ with the same relative paths and an .example suffix. The application logic in the contact/configuration templates is preserved; private field values are replaced. Employee templates contain an empty array rather than real records.

Restore your authorized private copies at their original paths before running tests, rebuilding Public or deploying. A template is not a ready-to-deploy staff dataset: the existing importer validates exactly 70 employees across nine departments. Do not deploy empty placeholders against a live database. Existing local private files were preserved during synchronization.

Backups, temporary previews, logs, test screenshots, historical source mirrors, live maintenance receipts and temporary maintenance access helpers remain local. The repository includes current build tools, app manifests, logic, test code, vendor dependencies and relevant Markdown documentation. No Google Sheets exports or private Drive document contents are included.

Three test originals repeat private contact values and are also excluded, with matching placeholder copies under config-templates/:

- local-test/test/public-project.test.js
- local-test/test/tdd-form.test.js
- local-test/test/tld-form.test.js

Restore these private test originals as well for the full existing test suite. No existing application or test file was edited for this baseline.
